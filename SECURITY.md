# Security policy

## Supported versions

The latest released version of GitHookDoctor receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability reporting:
https://github.com/6t9xstar/git-hook-doctor/security/advisories/new

You will get a response within 7 days. GitHookDoctor runs locally, only reads your repository and Git config, and never changes anything without your approval. It has no telemetry.
